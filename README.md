# VK Маркет — интерактивная модель

Кликабельный интерфейс покупателя и продавца для проекта VK Case Champ 2026. Структура основана на концепции Маркета с товарами из сообществ, шопсами, дропами, заказами и аналитикой. Визуальное оформление ориентируется на компоненты и дизайн-токены VKUI и приложенный референс VK AdBlogger.

## Запуск

Откройте `index.html` или запустите локальный сервер из корня папки:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

Никаких сборок и зависимостей нет. Для работы товарных фотографий папка `assets/` должна лежать рядом с `index.html`, `app.js` и `styles.css`.

## Сценарии

**Покупатель:** каталог, поиск и фильтры, избранное, карточки товаров и сообществ, шопсы из публикаций, ограниченные дропы, корзина одного продавца, расчёт доставки до Рыбинска с учётом города отправки, оформление заказа, история доставки, возвраты и отзывы.

**Продавец:** кабинет «Речной Бисквит», каталог и остатки, заказы, отправления, возвраты, собственные дропы, переход в сообщество, аналитика публикаций, среднего чека, рейтингов и комиссии Маркета.

Магазины представлены из разных регионов России; Рыбинск — фиксированный город покупателя для текущего сценария, а не ограничение платформы.

## Онбординг

После первого выбора роли открывается интерактивное знакомство с пятью темами:

1. **Шопсы** — товар в посте и переход к покупке.
2. **Дропы** — анонс, напоминание, запуск коллекции.
3. **Доставка** — методы получения, отслеживание, возвраты.
4. **Аналитика** — показатели контента, заказов, комиссии и отзывов.
5. **Сообщества** — связь существующего VK-сообщества с витриной товаров.

Можно листать шаги вперёд и назад, пропускать, завершать и переходить к работающим примерам. Повторно онбординг открывается через **«Как это работает» в левом меню**. Сведения о прохождении хранятся отдельно от заказов в `localStorage` (`vk-market-intro-v1`). Кнопка **«Сменить режим»** находится только в левом меню.

## Что важно про данные

Это локальная учебная модель, не действующий сервис VK и не подключённый маркетплейс. Сведения о магазинах и публикациях иллюстративные. Заказы, статусы, отзывы, начисления и возвраты сохраняются в `localStorage` браузера; реальных платежей, отправлений, резервирования между устройствами, интеграций VK, СДЭК или Яндекс Маркета нет.

Для расчёта комиссии используется условная ставка **5%** — это параметр демонстрации, а не официальный тариф VK. Данные аналитики публикаций не следует складывать с оформленными в браузере заказами.

В интерфейсе убраны декоративные надписи о конкурсе и тестовом статусе. В критически важных сценариях — оплате, доставке, возврате средств и аналитике — оставлены пояснения о том, что действия не являются реальными транзакциями.

## Файлы

- `index.html` — точка входа.
- `styles.css` — интерфейс, адаптивная сетка, компоненты VK-style и дизайн онбординга.
- `app.js` — все сценарии, данные и обработчики.
- `assets/` — 30 локальных изображений товаров.

Для обновления текущей ветки достаточно заменить `app.js`, `styles.css` и `README.md`. Все изображения остались прежними.

Проект не аффилирован с VK. Справочная информация по интерфейсу: https://vkui.io/overview/design-tokens/.
