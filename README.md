# VK Маркет · интерактивный пилот

Кликабельный прототип социальной коммерции для **VK Case Champ 2026**. Интерфейс основан на дизайн-принципах VK/VKUI: системные цвета, голубой акцент, белые панели, компактные контролы, плавные переходы и адаптивная сетка. Исходная продуктовая концепция — `VK_Market_pilot_product_spec_2026.docx` (передана командой).

## Как запустить

Проект — статический HTML/CSS/JavaScript, без сборки, npm-зависимостей и серверного API.

```bash
python3 -m http.server 8080
```

Открыть `http://localhost:8080`. Можно также открыть `index.html` напрямую. Подходит для GitHub Pages (корень ветки `main`).

## Покупатель

- Главная с категориями, подборками и подбором товаров из сообществ.
- Поиск и фильтры по категории, наличию, цене, сортировке.
- Карточка товара и страница продавца с переходом в существующее VK-сообщество.
- Избранное, подписки, корзина **одного продавца**, демонстрационный чекаут.
- Профиль и история заказов со статусами.
- Дроп с анонсом, подпиской, управляемым демонстрационным запуском и состоянием «распродано».

## Продавец

- Подключение существующего сообщества (демонстрация проверки прав).
- Обзор: заказы, выручка, товары, остатки, дропы.
- Каталог: добавление/редактирование товара, управление остатками.
- Заказы: смена статуса (новый → подтверждён → сборка → отправлен → завершён), отмена.
- Дропы: создать, анонсировать, запустить, завершить, посмотреть продажи.
- Аналитика → Шопсы: период, источники, открытия карточек, оформленные заказы, конверсия и таблица публикаций.

## Важные ограничения

**Это демонстрационный прототип, не реальный сервис VK.** Товары, продавцы, охваты и продажи синтетические и обозначены как пример. Действия сохраняются в `localStorage` текущего браузера. Реальных списаний, платежей, резервирования между устройствами, доставки и уведомлений VK нет. В демонстрационном чекауте заказ создаётся, но считается **неоплаченным**. Для боевого пилота потребуются backend, атомарный резерв, проверка доступа к сообществу, реальные статусы оплаты и согласованные интеграции VK.

Ссылка на сообщество ведёт в VK; тестовые сообщества/товары вымышлены. Публикации в аналитике представляют демонстрационный пример и не устанавливают реальную атрибуцию заказов. Кнопка «Сбросить демо» удаляет локальные изменения.

## Технологии

Vanilla JS, CSS custom properties, inline SVG; мобильная адаптация, dark mode, `prefers-reduced-motion`, доступные названия кнопок, навигация через URL hash. Внешние изображения товаров загружаются с Unsplash (при отсутствии сети показываются цветные плейсхолдеры).
