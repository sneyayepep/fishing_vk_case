# VK Маркет — интерактивный прототип

Кликабельный прототип покупательского Маркета и кабинета продавца «Речной Бисквит». Проект не является официальным сервисом VK.

## Запуск

Откройте `index.html` в браузере. При необходимости локального сервера:

```bash
python -m http.server 8080
```

После запуска откройте `http://localhost:8080`. Сборка и установка зависимостей не требуются. Изображения находятся локально в папке `assets`, её нужно сохранить при копировании проекта.

## Возможности

- Покупатель: каталог, поиск, фильтры, товары и сообщества, шопсы, дропы, отзывы и рейтинги, избранное, корзина, доставка и обращения по заказам.
- Продавец: товары, заказы, отправления, возвраты, дропы, публикации сообщества, аналитика и условная комиссия Маркета.
- Рыбинск указан как выбранный город покупателя для демонстрации; продавцы находятся в разных регионах. Реальные тарифы доставки не подключены.

## Гибридное интерактивное обучение

На первом входе предлагаются отдельные маршруты для покупателя и продавца. Обучение также можно снова запустить через пункт **«Как это работает»** в левом меню.

**Покупатель — 17 шагов:** каталог → карточка → цена → описание → изготовление и доставка → отзывы → сообщество → шопс → главная → дроп → напоминание → добавление товара → корзина → оформление доставки → история заказов → возвраты.

**Продавец — 13 шагов:** магазин → управление товарами → редактор → сообщество и шопсы → дроп и форма создания → заказы → возвраты → аналитика → комиссия → условия доставки.

- Нажимаемые кнопки выделены синей рамкой и стрелкой **без затемнения**. Можно нажать саму кнопку либо «Далее».
- Информационные блоки, например отзывы или расчёт комиссии, выделены целиком на мягко затемнённом фоне. Подсказка размещается **вне выделенной области**.
- На мобильных экранах крупные блоки обводятся без затемнения, чтобы сохранить видимость контента. При показе окна оформления доставки подсказка занимает отдельную верхнюю зону, а всё окно остаётся светлым и доступным для прокрутки.
- «Назад» возвращает к предыдущему шагу. «Пропустить обучение» завершает тур. Прогресс незавершённого тура сохраняется в рамках вкладки.

## Ограничения

Товары, показатели публикаций, комиссии, доставка, оплата, статусы, отзывы и возвраты — демонстрационные данные или имитации действий. Реальные деньги не списываются, уведомления и отправления не создаются. Изменения сохраняются в `localStorage` браузера; это не серверная база данных.

Для действующего маркетплейса потребуются авторизация, backend, проверка прав владельца сообщества, обработка конкурентных заказов, платёжная и логистическая интеграции и согласованные правила обработки персональных данных.
